## Mandatory agent skill usage

For any non-trivial Java backend implementation,
domain modeling, Spring Boot feature, repository/
persistence change, architectural refactor,
or architecture review:

1. Load the `clean-architecture` skill before
   designing or editing code.

2. Read its instructions and relevant references.

3. Inspect other installed skills and use those
   relevant to Java, Spring Boot, testing,
   or architecture only if actually available.

4. Apply the skill pragmatically, respecting
   existing architecture and conventions.
