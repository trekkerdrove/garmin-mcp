# Revue des interfaces

Verdict. Les deux liaisons OAuth sont distinctes et la condition `issuer + audience + sub` protège l’accès au compte Garmin. L’enregistrement de la connexion dans ChatGPT et les transitions Render restent à préciser.

1. **Élevé · Faire coïncider le mode OAuth ChatGPT avec AD-2.** Le serveur décrit exige un jeton sur tout `/mcp`. Dans le menu ChatGPT, choisir explicitement **OAuth**. Le mode mixte lance la découverte MCP sans jeton, donc son premier appel échouerait avec le filtre actuel. Si une future version opte pour le mode mixte, seules les métadonnées et la liste des outils peuvent être publiques. Les outils déclarent OAuth et renvoient le défi MCP au besoin. [Configuration ChatGPT](https://developers.openai.com/api/docs/guides/custom-mcp-server) · [Authentification des outils](https://developers.openai.com/plugins/build/auth)
2. **Moyen · Définir une identité et une URL canoniques par environnement.** Faire dériver l’audience, le champ `resource` et l’enregistrement WorkOS d’une seule valeur configurée, le `/mcp` HTTPS exact. Publier l’URL précise des métadonnées dans le défi `WWW-Authenticate`. Définir le couple `issuer + sub` pour chaque environnement avant d’activer Garmin. Le jeton d’un autre environnement doit être refusé avant tout appel Garmin. Tester la demande de renouvellement depuis le client avec l’issuer de production. [Indicateurs de ressource AuthKit](https://workos.com/docs/authkit/mcp) · [Claims WorkOS](https://workos.com/docs/authkit/connect/token-claims)
3. **Moyen · Rendre disponible le premier déploiement sans ouvrir le MCP.** Le premier déploiement doit pouvoir obtenir son URL Render et répondre à `/health` avant la configuration OAuth. Les méthodes métiers restent fermées dans cet état. Ensuite, vérifier qu’un appel MCP autorisé fonctionne sur données fictives, que le cas anonyme et le cas autre utilisateur n’accèdent jamais à Garmin, puis ajouter le secret Garmin à l’exécution. Render présente les variables d’environnement sous forme d’arguments Docker au build. Garder la clé hors des déclarations et commandes du Dockerfile, et réutiliser l’image via **Save and deploy** pour la première injection. [Docker Render](https://render.com/docs/docker) · [Variables d’environnement Render](https://render.com/docs/configure-environment-variables)
4. **Moyen · Fixer les conventions qui font varier un même résultat entre deux implémentations.** Indiquer que toute période acceptée ou émise représente les dates locales inclusives au format ISO, que le décompte déduplique les activités Garmin par identifiant et que l’écart du sommeil suit une convention signée commune. Les clés exactes du JSON peuvent être décidées dans chaque story.

Contrôle documentaire uniquement. L’ajout dans ChatGPT et les réponses OAuth doivent être confirmés sur le compte concerné.
